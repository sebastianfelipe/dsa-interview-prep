# Study Plans

Pick a plan based on time until interviews.

| Plan | File | Audience |
|------|------|----------|
| 2 weeks intensive | [2-week.md](./2-week.md) | Refresh + high-frequency patterns |
| 4 weeks solid | [4-week.md](./4-week.md) | First serious prep |
| 8 weeks mastery | [8-week.md](./8-week.md) | Deeper coverage + mock interviews |

## Daily session shape (any plan)

1. **15 min** — review Key Extracts / flashcards  
2. **45–75 min** — 1–2 timed problems (no peeking)  
3. **15 min** — compare solution, write your own Key Extract  
4. **Optional** — re-code yesterday's problem from memory  

## Tracking

Keep a simple log: `date | problem | pattern | solved? | time | extract written?`
