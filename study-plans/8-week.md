# 8-Week Mastery Plan

**Goal:** Strong medium + selective hard; ready for FAANG-style loops.

| Week | Theme | Depth |
|------|-------|-------|
| 1 | Fundamentals, arrays, hashing | All patterns in `01`–`02` |
| 2 | Linked lists, stacks, queues | Monotonic stack mastery |
| 3 | Trees + BST + tries | `05` + `15` |
| 4 | Graphs + Union-Find + topo | `06` + `16` |
| 5 | Heaps + intervals + greedy | `07`, `10`, `14` |
| 6 | Backtracking + bit + math | `08`, `12`, `13` |
| 7 | Dynamic programming deep dive | All `09` patterns + 15 DP problems |
| 8 | Mixed mocks, binary search on answer, weak spots | 4+ timed mocks |

## Extra habits

- One **hard** problem per week (don't panic; extract the pattern).
- Record yourself once in week 4 and week 8; fix filler words and silence gaps.
- Maintain a "missed recognition" list — problems where you picked the wrong pattern first.

## Key Extract

By week 8 you should open a random medium, name the pattern in <60s, and implement in <25 min.
