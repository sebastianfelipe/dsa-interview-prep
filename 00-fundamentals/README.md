## Mental model

Every LeetCode-style problem is usually one of:

1. **Traverse** something (array, tree, graph)
2. **Search** for a value / boundary / feasibility
3. **Optimize** under constraints (DP, greedy, heap)
4. **Transform** data (hash, sort, stack) to unlock a simpler view

Your job in the first 5 minutes is to classify the problem into a **pattern family**, not invent a novel algorithm from scratch.
