# Pattern Recognition Flashcards

Quiz yourself: cover the right column.

| If you hear / see… | Think… |
|--------------------|--------|
| "longest substring without repeating" | Variable sliding window + set/map |
| "subarray sum equals k" | Prefix sum + hash of counts |
| "two sum" (unsorted) | Hash complement |
| "two sum" (sorted) | Two pointers |
| "container with most water" / "trapping rain" | Two pointers / stack |
| "next greater element" | Monotonic stack |
| "largest rectangle in histogram" | Monotonic stack |
| "validate parentheses" / "decode string" | Stack |
| "cycle in linked list" / "middle node" | Fast & slow |
| "reverse list" / "palindrome list" | Reverse (partial) |
| "level order" / "zigzag tree" | BFS queue |
| "max path sum" / "diameter" | DFS returning values |
| "number of islands" | DFS/BFS flood fill |
| "course schedule" | Topological sort / cycle detection |
| "kth largest" | Min-heap of size k |
| "merge k sorted lists" | Heap of heads |
| "median from data stream" | Two heaps |
| "all subsets / permutations" | Backtracking |
| "word search in grid" | Backtracking / trie |
| "climb stairs" / "house robber" | 1D DP |
| "unique paths" / "min path sum" | Grid DP |
| "coin change" | Unbounded knapsack DP |
| "longest increasing subsequence" | DP O(n²) or patience O(n log n) |
| "jump game" | Greedy reach |
| "merge intervals" | Sort by start |
| "meeting rooms II" | Sweep / min-heap of ends |
| "search in rotated sorted array" | Modified binary search |
| "capacity to ship packages" / "split array largest sum" | Binary search on answer |
| "single number" (others twice) | XOR |
| "implement autocomplete" | Trie |

## Key Extract

Train recognition until it is automatic. Coding is the easy part after that.
